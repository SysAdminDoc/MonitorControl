The [selection record](selection.json) identifies the approved source and master. The shipping [application icon](../monitorcontrol-app-icon.png) keeps the established outline treatment, with the [transparent production mark](../monitorcontrol-mark.png) available for other surfaces. This archive doesn't change either file.

The checkerboard in studies 01, 02, and 04 is baked into the original pixels. Those files are deliberately preserved as received, not advertised as transparent assets. Use the production mark when a real transparent background is needed.
